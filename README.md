# 50 Model Rocket Projects for the Evil Genius

Welcome to the official repository for the source code and supplemental data associated with the book *"50 Model Rocket Projects for the Evil Genius"* by Gavin D. J. Harper.

## Overview
This repository contains the software and data files required to build and run the various projects described in the book. Whether you are a newcomer to countdowns or a veteran rocket scientist, these projects are designed to take your rocketry to the next level.

### Projects Covered
The files in this repository support projects including:
- Delay Timers and Magnetic Apogee Detection
- Barometric Altimeters and Pressure/Altitude data
- Temperature, Humidity, and Vibration data loggers
- Accelerometer and Roll Rate loggers
- Thermocouple data logging and lookup tables
- Data Acquisition Systems

## Directory Structure
- `/code`: Basic Stamp (.bas) source code files.
- `/data`: Supplemental Excel (.xls) spreadsheets.
- `/tables`: Lookup tables (.bpe) for sensor data.

## Getting Started
1. **Basic Stamp Environment**: The code provided is written for the Basic Stamp platform. You will need the appropriate development environment to compile and upload these files.
2. **Data Files**: Use Microsoft Excel or an open-source alternative like LibreOffice Calc to view the `.xls` data files.
